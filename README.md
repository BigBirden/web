## Инструкция по установке
1. Установите Node.js с официального сайта. При установке оставьте стандартные параметры.
1.1. Для проверки установки вы можете ввести в командной строке:
````bash
node --version
````
````bash
npm --version
````
2. Для установки зависимостей серверной части введите в корневом каталоге проекта команду:
````bash
npm install
````
3. Перейдите в папку ``dss-app``.
4. Для установки зависимостей введите команду:
````bash
npm ci
````
Если при установке зависимости возникнут ошибки, попробуйте запустить эту команду с использованием старого алгоритма обработки peer-dependency:
````bash
npm ci --legacy-peer-deps
````

## Запуск проекта
Запуск проекта состоит из включения backend- и frontend-части.
### Запуск Backend
1. В корневом каталоге проекта ведите команду:
````bash
npm run start:dev
````
2. При успешном запуске последнее выведенное в консоли сообщение будет ``Example app listening on port 3000``.
3. Сервер запущен. Не закрывайте окно консоли до окончания работы, иначе сервер выключится. Для отключения также можно использовать сочетание клавиш ``CTRL+C`` и на выпадающий в консоли вопрос ввести ``Y``.
